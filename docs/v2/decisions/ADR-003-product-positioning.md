# ADR-003 - Product Positioning

Date: 2026-08-02

## Context

V2 could remain a tracker, become a blocker, or connect tracking and control through user intent.

## Options

### A. Private browsing analytics tracker

- Benefit: Minimal conceptual change.
- Compromise: Passive value and limited differentiation beyond privacy/personality.

### B. Website blocker and focus timer

- Benefit: Clear utility and established category demand.
- Compromise: Crowded, easy to bypass, and underuses current insights.

### C. Intentional browsing system - recommended

- Benefit: Unifies plans, focus, intervention, tabs, wellbeing, analytics, personality, and Wrapped.
- Compromise: Requires disciplined UX and accurate intent modeling.

## Recommendation

Position Tabyss as a privacy-first intentional-browsing productivity extension, using “Plan, focus, recover, reflect” as the product loop.

## Validation

- Concept test all three positions.
- Measure five-second comprehension, install interest, permission comfort, uniqueness, and expected weekly use.

## Status

Proposed.
