## ADR format

- Date and title.
- Context.
- Decision drivers.
- Options with benefits and compromises.
- Recommendation/decision.
- Consequences.
- Validation.
- Status: Proposed, Accepted, Rejected, or Superseded.

An Accepted ADR may be changed only through a newer superseding ADR that links to the original.
